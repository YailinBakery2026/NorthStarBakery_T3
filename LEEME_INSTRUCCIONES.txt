NORTH STAR BAKERY — TOUCHSTONE 3

WHAT IS INCLUDED
index.html, products.html, about.html, contact.html, styles.css, north-star-bakery.mp4

IMPORTANT: ADD SIX REAL IMAGES FROM YOUR MAC
On your Mac open Desktop > Bakery_c. Select and copy the following six image files into THIS unzipped folder:
 - bakery-logo_c.png
 - bakery-storefront_c.png
 - bakery-feature-small_c.png
 - bakery-feature-large_c.png
 - bakery-bread_c.png
 - bakery-signature-loaf_c.png

If the images are not copied, their spaces will appear broken or blank in the website. Do not rename them.

HOW TO TEST
Double-click index.html and test Home, Products, About Us, Contact in the browser. Resize the browser window. Check images and video. The contact form is a demo and does not send messages.

HOW TO SUBMIT
Create a PUBLIC GitHub repository (for example north-star-bakery), upload all four HTML files, styles.css, the six image files and the MP4. In repository Settings > Pages, set Deploy from a branch > main > / (root), then save. Wait for the actual GitHub Pages URL to appear. Test it in a private browsing window.

In Sophia Touchstone 3 Template, insert the real public GitHub repository URL and the working GitHub Pages URL. The ZIP itself is not a substitute for public links.
